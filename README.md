# IITL-Stock-Analytics-Hub-NSE
Interactive quantitative stock analytics dashboard for IITL (NSE: IITL) built with Streamlit and Plotly. Features candlestick OHLC charts, moving averages, Bollinger Bands, RSI, MACD, underwater drawdown analysis, seasonal return heatmaps, trend forecasting, and CSV export across 3,200+ trading sessions (2012–2024).
